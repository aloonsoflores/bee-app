Política de privacidad

Última actualización: 23 de noviembre de 2026.

Quién la usa

Bee es una herramienta privada. Solo la usa su autor, con sus propios canales de YouTube. No tiene usuarios externos.

Qué datos usa

  • Permiso de acceso a YouTube (token OAuth) de cada canal del autor, para subir vídeos y leer sus estadísticas.
  • Datos de los propios vídeos: título, descripción, identificador, visitas, me gusta, número de comentarios y retención de la audiencia.

Bee no lee ni guarda datos de los espectadores, ni el texto de los comentarios, ni datos personales de terceros.

Dónde se guardan

Todo se guarda solo en el ordenador del autor. Los permisos de acceso, en una carpeta privada que no se sube a ningún repositorio ni a la nube. Las estadísticas, en una base de datos local. Las estadísticas se refrescan a diario y el autor puede borrarlas cuando quiera.

Con quién se comparten

Con nadie. Bee no vende, cede ni comparte datos, y no muestra publicidad.

Servicios de Google y YouTube

Bee usa los servicios de la API de YouTube. Al usarlos se aplican las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.

El uso que hace Bee de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el permiso

El permiso se puede retirar en cualquier momento desde la página de permisos de la cuenta de Google. Al retirarlo, el permiso guardado deja de valer y Bee ya no puede acceder al canal.

Privacy policy

Last updated: 23 November 2026.

Who uses it. Bee is a private tool used only by its author with his own YouTube channels. It has no external users.

Data used. The OAuth access token for each of the author's channels (to upload videos and read their statistics), and data about those videos: title, description, ID, views, likes, comment count and audience retention. Bee does not read or store viewer data, comment text or any third-party personal data.

Storage. Everything is stored only on the author's computer: tokens in a private folder never uploaded to any repository or cloud service, and statistics in a local database, refreshed daily and deletable by the author at any time.

Sharing. None. Bee does not sell, transfer or share any data and shows no ads.

Google and YouTube. Bee uses YouTube API Services. By using them, the YouTube Terms of Service and the Google Privacy Policy apply. Bee's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time from the Google account permissions page. Once revoked, the stored token stops working and Bee can no longer access the channel.
